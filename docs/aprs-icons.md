# Піктограми символів APRS (R14, R17)

Монохромні 24x24 (XBM, 72 байти кожна), const у flash — `MDUV380_firmware/application/source/functions/aprs_icons.c`. Малюються у вікні
маяка (x = 4, y = 100) через `displayDrawXBitmap()`; у вибірнику символу «Режиму APRS» — ті самі. Таблиця `/` — первинна, `\` — додаткова;
таблиця-цифра/літера — додаткова піктограма плюс знак таблиці в блоці 8x8 з інверсним тлом у правому нижньому куті (накладка).
Символу нема в наборі — рамка 24x24 із самим знаком (FONT_SIZE_1). Додаткова таблиця для кодів `> k u v s ^ _ & S` бере піктограму первинної.

Файл `aprs_icons.c` (масив `icons[]`) згенеровано скриптом `tools/gen_aprs_icons24.py` (підкоманда `c`), цей файл — підкомандою `md`.
