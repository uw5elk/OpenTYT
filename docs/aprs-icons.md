# Піктограми символів APRS (R14)

Монохромні 16x16 (XBM, 32 байти кожна), const у flash — `MDUV380_firmware/application/source/functions/aprs_icons.c`. Малюються у вікні
маяка (x = 4, y = 99) через `displayDrawXBitmap()`. Таблиця `/` — первинна, `\` — додаткова; таблиця-цифра/літера — додаткова піктограма
плюс знак таблиці в центрі (накладка). Символу нема в наборі — рамка 16x16 із самим знаком. Додаткова таблиця для кодів
`> k u v s ^ _ & S` бере піктограму первинної (авто, джип, вантажівка, фургон, яхта, літак, метео, шлюз, супутник).

Кадри з логу: репітер `/r` (ефір), шлюз — таблиця `R`, код `&` (APRS-IS) = піктограма шлюзу + накладка «R».
