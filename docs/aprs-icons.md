# Піктограми символів APRS (контактний аркуш)

Усі піктограми 24×24 (R20 Ж2) одним файлом — щоб переглянути набір і сказати, що перемалювати. Кожна піктограма показана напівблоками (`▀▄█`, два пікселі по висоті на знак), тож пропорції збережено. **Джерело** — `MDUV380_firmware/tools/aprs_icons.txt` (ASCII-сітки `#`/`.`; правте там і запускайте `python3 MDUV380_firmware/tools/aprs_icons_gen.py`). `MDUV380_firmware/application/source/functions/aprs_icons.c` і цей файл — згенеровані.

Таблиця `/` — первинна, `\` — додаткова; таблиця-цифра чи літера (накладка) малює піктограму додаткової таблиці й знак накладки в куті 8×8. Символи, яких тут нема, зарезервовані специфікацією APRS — для них прошивка малює рамку 24×24 зі знаком символу.

Усього піктограм: **170** кодів (унікальних зображень 161). У flash: пул A (первинна таблиця) 6336 Б + пул B (решта) 5256 Б + індекс 188 Б = **11780 Б**; діагностична збірка містить лише пул A.

## Коди без піктограми (18)

Таблиць по 94 коди (`!`…`~`), разом 188. Піктограм **170**, тож **18** кодів їх не мають — свідомо, а не пропуск: за актуальним переліком символів aprs.org (symbolsX.txt, звірено 2026-10) ці коди не мають значення: `/"` і `\"` — «reserved», `/Q` — «TBD», `/D` `/J` `/{` `/}` — без назви, `\1`…`\7`, `\Z`, `\]`, `\q` — «AVAIL» (вільні), `\}` — «AVAIL? (maybe)». Вигаданий малюнок для них вводив би в оману. Для них прошивка малює рамку 24×24 зі знаком символу, а у списку символів вони доступні вручну (таблиця + код). Якщо код колись отримає значення — додати малюнок у `tools/aprs_icons.txt` (72 Б на код; усі 18 — 1296 Б).

- Первинна таблиця `/`: `"` `D` `J` `Q` `{` `}`
- Додаткова таблиця `\`: `"` `1` `2` `3` `4` `5` `6` `7` `Z` `]` `q` `}`
