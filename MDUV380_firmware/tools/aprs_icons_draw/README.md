# aprs_icons_draw -- код малювання піктограм APRS 24×24 (R20-fix)

Власне малювання (жодних чужих зображень). Результат -- `tools/aprs_icons.txt` (ASCII-сітки; з нього `tools/aprs_icons_gen.py` робить `aprs_icons.c` і
`docs/aprs-icons.md`). `build.py` перемальовує весь txt з цього коду; ручні правки txt після запуску втрачаються.

Чому перемальовано (R20-fix): перша версія малювалась навколо колонки 12, а центр кадру 24 px лежить між колонками 11 і 12 -- кола, щити й літаки виходили
несиметричними («кривими»). `nd.py` рахує в координатах країв пікселів (0..24, центр (12, 12)), піксель вмикається при покритті ≥ 50%, тож симетричні фігури
дають симетричну картинку. Симетричність 72 символів перевіряє `tools/aprs_icons_gen.py` (`SYMMETRIC_LR`).

Файли: `nd.py` (бібліотека), `prim_*.py` (первинна таблиця `/`), `alt_*.py` (додаткова `\`), `fixes.py` (пізніші перекриття), `build.py`.
Усі модулі наповнюють один словник `D[ключ]`, пізніші модулі перекривають ранні.
