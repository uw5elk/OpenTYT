# tools/lab

Лабораторні скрипти й знімки, на які не посилається жоден тест, CI-крок чи документ (перевірено grep-ом у R105-RELDOCS).
Переміщено з tools/ без змін, нічого не видалено: `flasher_current.png`, `flasher_new.png` (знімки старого вигляду прошивальника),
`genamvoice.py`, `iq_to_disc_wav.py`, `menu_sms_test.py`. Запускати з цього каталогу або вказавши шлях; скрипти можуть потребувати
правки відносних шляхів (`sys.path`, `tools/...`), бо раніше лежали в `tools/`.
