# Стартова точка для піктограм APRS (R20 Ж2)

**Це не частина збірки і не джерело правди.** Джерело правди — `MDUV380_firmware/tools/aprs_icons.txt` (ASCII-сітки 24×24, їх правлять руками); з нього
`tools/aprs_icons_gen.py` робить `aprs_icons.c` і `docs/aprs-icons.md`.

Тут — скрипти, якими сітки було вперше намальовано (примітиви: прямокутник, еліпс, ламана, дуга, 5×7-шрифт для написів на кшталт «BBS»/«NTS»):
`gen_aprs_icons24.py` (R17, 24 перші піктограми), `seed_lib.py` (бібліотека малювання), `icons_prim1.py`/`icons_alt.py` (первинна й додаткова таблиці), `names.py` (нові українські назви).
`python3 seed_main.py txt /шлях/aprs_icons.txt` перезапише сітки з нуля — **затре ручні правки в aprs_icons.txt**, тож користуйтеся лише для нових піктограм, а не для виправлень.
Потрібен `python3` (PIL лише для `sheet_png`, у збірці не використовується).
